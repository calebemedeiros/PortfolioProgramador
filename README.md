Este repositório serve como um **Modelo de Portfólio** pronto para uso, demonstrando minhas habilidades em desenvolvimento Front-end através de um design limpo, responsivo e de fácil customização.

---

## ✨ Visão Geral

Este projeto atua como um cartão de visitas profissional é um **template completo de Portfólio de Programador**, desenvolvido para servir como uma base sólida e profissional para quem deseja exibir suas habilidades e projetos.


**O que você encontrará:**

* **Página "Sobre Mim":** Detalhes sobre formação e soft skills.
* **Seção de Habilidades:** Apresentação visual das tecnologias (Front-end, Back-end e Ferramentas).
* **Galeria de Projetos:** Links diretos para os repositórios.
* **Formulário de Contato:** Uma maneira fácil para recrutadores e colaboradores entrarem em contato.

**Ele foi construído com foco em:**

* **Design Responsivo:** Adaptado perfeitamente para desktop, tablet e mobile (`mobile.css`).
* **Código Limpo:** Estrutura organizada e modular para fácil manutenção.
* **Customização Rápida:** Conteúdo pronto para ser substituído pelos dados do novo usuário.

---

## 🎯 Objetivo do Modelo

O principal objetivo deste template é **demonstrar minhas capacidades técnicas** em construir aplicações Front-end de qualidade, incluindo:

1.  **Habilidade em Estruturação:** Uso de HTML semântico e acessível.
2.  **Habilidade em Estilização:** Domínio de CSS para layouts flexíveis e responsivos.
3.  **Preparação para Interatividade:** Base pronta para a integração de lógica JavaScript.

Ele é o modelo para mostrar o nível de qualidade que posso entregar em um projeto.

---

## 🚀 Tecnologias Utilizadas

O template foi construído com foco em performance, responsividade e boas práticas, com as tecnologias fundamentais da web:


* **HTML5** → Estrutura semântica do projeto.
* **CSS3** → Estilização completa, com foco em Flexbox/Grid e Media Queries e responsividade (incluindo o arquivo `mobile.css`).
* **JavaScript (ES6+)** → Estrutura para futura implementação de interatividade e manipulação de DOM (e.g., navegação, animações, lógica de formulário).

## 🏗️ Estrutura do Projeto

A organização do código segue um padrão simples e direto, facilitando a manutenção e a visualização:


## 📌 Como Customizar

Se você deseja usar este modelo para seu próprio portfólio, siga estes passos:

1.  **Clone o Repositório:**
    ```bash
    git clone https://github.com/calebemedeiros/PortfolioProgramador.git
    ```
2.  **Crie seu Próprio Repositório:** Crie um novo repositório no seu GitHub (ex: `meu-portfolio`).
3.  **Altere o Conteúdo:**
    * Substitua o texto em `index.html` e nos arquivos de estilo com seus dados pessoais, projetos e informações de contato.
    * Substitua as imagens na pasta `images/`.
4.  **Publique:** Envie o código para o seu novo repositório e configure o GitHub Pages.
